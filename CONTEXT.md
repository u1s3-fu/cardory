# Cardory Workspace

Cardory organizes project work, its tasks, progress, assets, and files in a local-first workspace.

## Language

**Project**:
A body of work that owns its progress, tasks, assets, and attachments.

**Asset**:
Software or hardware recorded under a project. An asset does not own attachments.

**Project attachment**:
An encrypted file associated directly with one project, with a kind and creation date.
_Avoid_: Asset attachment, uploaded asset

**Attachment kind**:
The explicit project attachment category: image, document, archive, or other.
_Avoid_: Asset type
